### 커스텀 예외 처리 핸들링 구현 문제

문제 상황 :
- 서비스 전반에서 발생하는 예외를 통일된 방식으로 처리하고자 커스텀 예외를 구현하는 과정에서 어려움 발생
- 하나의 클래스에서 서비스 전반에서 발생하는 예외를 다루기에는 유지보수나 책임에 있어서 좋지 않다고 판단

문제 해결 방안 :
- 블로그 자료를 참고하여 기본 구조를 학습 후 구현
- 도메인 별 에러 코드를 분리하여 관리
- 유지보수에 용이하고, 도메인 별 책임이 명확하게 구분되도록 설계

### 테스트 코드 의존성 문제

문제 상황 :
- 테스트 코드를 작성하면서 객체의 의존성 주입에 실패하여 생기는 문제 발생
- Spring Test Context에 필요한 Bean이 자동 주입이 되지 않음

문제 해결 방안 :
- `@SpringBootTest` 어노테이션으로 Spring Test Context 로드
- 의존성 주입이 필요한 필드에 `@Autowired` 어노테이션을 사용하여 Spring 컨테이너가 자동으로 의존성 주입
